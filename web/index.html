Keep Non-Mac Disks Clean

Copy a file to a USB stick, an SD card or a Windows share and macOS leaves debris behind: .DS_Store files, and ._ AppleDouble companions that carry the extended attributes the filesystem cannot store. They show up on Windows, on Linux, on cameras and on TVs. dotclean removes them — live, as they appear, or on demand from the Finder with a preview of exactly what will go. It runs as you, not as root: no daemon, no installer, no administrator password.

What It Removes

Deleted from non-Mac volumes

  • ._ AppleDouble files
  • .DS_Store
  • .AppleDouble folders
  • __MACOSX folders
  • Thumbs.db and desktop.ini
  • .apdisk, .VolumeIcon.icns
  • .Trashes, .Spotlight-V100, .fseventsd (on demand only)
  • $Recycle.bin, System Volume Information (on demand only)

Never touched

  • Any APFS or HFS+ volume — Mac disks are left alone by default
  • ._ files for fonts and artwork, where the companion file is the data
  • Mount points, and anything outside the volume you selected
  • Symlinks are never followed
  • Your actual files

How it works

dotclean listens to the filesystem with a single FSEvents stream rooted at / and filters events by mount point, so plugging in a stick never needs a restart. Anything matching a rule on a non-Mac volume is removed immediately. If the kernel ever drops events under heavy load, the affected subtree is re-scanned instead of being ignored. Every deletion is written to ~/Library/Logs/DotClean/dotclean.log.

On-demand cleans run the same rule engine in two phases — scan, then delete — so the list you approve is the list that gets removed. Files are checked again immediately before each unlink: same volume, not a mount point, not a symlink.
